# refs

Reference images that image jobs may send to the model (`reference_images: ["refs/..."]`). Only files committed here
can be used by path; nothing outside `refs/` can be read.

| Folder | What |
|---|---|
| `peek/` | Peek, the Earth Report alien spy: the four approved poses from `channel-earth-report/brand/peek/` |

When a generated character sheet is approved, commit it here (e.g. `peek/peek-3d-turnaround.png`) and use it as the
reference for every later shot, so the character stays the same from Short to Short.
